## 説明文

```
マチスコアは、日本全国1,896の市区町村を「お店の多さ」で採点するアプリです。

町の名前を検索するだけで、暮らしに関わる5つのジャンルについて、その町が全国で何位なのかが100点満点のスコアでわかります。

■ 5つのジャンルで採点
・専門料理店（和食・中華・各国料理など）
・喫茶店
・食料品店・スーパー
・美容室
・娯楽施設

■ 主な機能

【マチスコア】
昼間人口1万人あたりの事業所数を全国順位に直し、100点満点に換算します。5つのジャンルの点数はレーダーチャートで表示され、町の個性がひと目でわかります。

【全国順位・県内順位・規模別順位】
「全国44位」だけでなく「北海道で3位」「同じ規模の町の中で13位」も表示。いろいろな角度から町の立ち位置がわかります。

【似ている町】
点数の並びが近い町を探せます。札幌市中央区には岡山市北区や名古屋市千種区が並ぶなど、性格の近い町がつながります。

【くらべる】
最大3つの町を並べて比較できます。引っ越し先の検討や、地元と他の町の違いを知るのに。

【5年間の変化】
2016年と2021年を比べ、お店が増えた町・減った町がわかります。

【全国ランキング】
ジャンルごとの上位100件を閲覧できます。

【マイタウン】
自分の町を登録すると、次に開いたときすぐスコアが表示されます。

【現在地から探す】
いま居る町のスコアをすぐに確認できます。

■ データについて
総務省統計局の公的統計（経済センサス活動調査・国勢調査）にもとづいています。
・事業所数：2021年 経済センサス活動調査（民営事業所）
・5年前の比較：2016年 経済センサス活動調査
・人口：2020年 国勢調査（従業地・通学地集計の昼間人口）
・人口増減率・面積・人口密度：2025年 国勢調査

すべてのデータはアプリに内蔵されており、通信せずに動作します。

■ ご注意
・昼間人口が1,000人未満の市区町村は、事業所数がわずかで数値が大きく振れるため、スコアと順位の対象外としています。
・スコアはお店の多さを表すものであり、町の優劣を示すものではありません。
```

## プライバシー

### App Privacy（データ収集）

**「データを収集しません」を選択する。**

根拠:
- 通信を行わない（統計データはアプリに内蔵）
- 解析・広告SDKを組み込んでいない
- 位置情報は端末内で市区町村名に変換するのみで、外部送信も保存もしない
- マイタウンの登録内容は端末内（UserDefaults）にのみ保存

### 位置情報の利用目的（Info.plist に記載済み）

```
現在地の市区町村を自動で調べてスコアを表示するために使います。
位置情報が外部に送信されることはありません。
```

### プライバシーポリシー

App Store Connect では**プライバシーポリシーURLが必須**。
`docs/privacy_policy.md` の内容を公開ページとして用意する必要がある。
