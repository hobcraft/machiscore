# マチスコア

日本全国 1,896 の市区町村を「お店の多さ」で採点する iOS アプリです。

町の名前を検索すると、暮らしに関わる5つのジャンル（専門料理店・喫茶店・食料品店/スーパー・美容室・娯楽施設）について、
その町が全国で何位なのかが 100 点満点のスコアでわかります。

## スコアの作り方

1. 事業所数を昼間人口 1 万人あたりに直します
2. その密度で全国の市区町村を並べ、順位を出します
3. 順位を 100 点満点に置き換えます（1位が100点、最下位が0点）

分母に夜間人口ではなく昼間人口を使っています。お店が相手にするのは、その町に昼間いる人だからです。
昼間人口が 1,000 人に満たない市区町村は、1 軒の増減で密度が大きく動くため、スコアと順位の対象外にしています。

## データの出典

- 民営事業所数: 2021年・2016年 経済センサス活動調査
- 昼間人口・高齢化率: 2020年 国勢調査
- 人口増減率・面積・人口密度: 2025年 国勢調査

いずれも政府統計の総合窓口（e-Stat）で公開されている総務省統計局の統計です。
経済センサス活動調査は経済産業省との共同実施です。

地図の中心に使う市区町村の代表点は
[Geolonia 住所データ](https://github.com/geolonia/japanese-addresses)（CC BY 4.0）を利用しています。

## ご注意

スコアはお店の多さを表すものであり、町の優劣や住みやすさを示すものではありません。
公共交通、自然環境、子育て支援、家賃など、町を選ぶうえで大切な要素の多くはこの数値に含まれていません。
